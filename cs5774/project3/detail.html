Prime Number Function

AI-Generated Response


def is_prime(n):
    """
    Return True if n is a prime number, otherwise False.

    Checks divisibility by every integer from 2 up to the square root of n,
    which keeps the loop short for large n.
    """

    for i in range(2, int(n ** 0.5) + 1):
    if n % i == 0:
        return False
    return True
                                    
    # Example usage
    print(is_prime(2))      # True
    print(is_prime(15))     # False
    print(is_prime(97))     # True

Evaluator Notes

The square-root bound is correct and the function is fast, and the docstring clearly explains the approach. However, the model never handles small inputs: is_prime(1), is_prime(0), and is_prime(-7) all return True because the loop body never runs.

A single guard such as if n < 2: return False fixes it. This is the third GPT-5 case this month where an edge case below the normal input range was skipped.
